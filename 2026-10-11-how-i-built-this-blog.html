How I built this blog

2026-10-11

This blog is plain python, HTML and CSS, no frameworks. Each post is a text file whose name carries the date and slug with the title on the first line.

I write posts in an admin page which only runs on my own laptop. When I hit publish, it builds a static HTML pages and pushes to GitHub pages, so nothing runs on the public side[as of now, I have new features coming which may change this].

For now there is an RSS feed to follow along.
